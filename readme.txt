Pro widgets and features for Wise Addons for Elementor.

== Description ==

Wise Addons for Elementor Pro adds Pro widgets and features to the free Wise Addons for Elementor plugin. Every Pro item appears in the Wise Addons dashboard with a "Pro" badge, where you can switch it on or off, and loads its CSS and JavaScript only on pages that use it.

= Pro widgets =

* Mega Menu
* Post Carousel
* Product Grid (WooCommerce)
* Table of Contents

= Pro features =

* Display Conditions
* Sticky Element
* Particle Effects
* Image Masking
* Horizontal Scroll
* Live Copy

= Requirements =

* Elementor
* Wise Addons for Elementor 1.1.0 or newer (free, from WordPress.org)
* An active Wise Addons Pro license for updates. The Pro features keep working after a license expires.

== Installation ==

1. Install and activate Elementor and the free Wise Addons for Elementor plugin.
2. Go to Plugins → Add New Plugin → Upload Plugin and upload the Pro zip.
3. Activate it, then open Wise Addons → Pro License and enter your license key.

== External services ==

This plugin connects to two services run for Wisemattic:

* Lemon Squeezy license API (https://api.lemonsqueezy.com/v1/licenses/), when you activate, check or deactivate your license and once a day. It sends the license key, the activation ID and your site's address. Terms: https://www.lemonsqueezy.com/terms, Privacy: https://www.lemonsqueezy.com/privacy
* Wisemattic update server (https://wisemattic.com/wp-json/wisemattic-updates/v1/), when WordPress checks for plugin updates. Downloads send the license key and activation ID. Privacy: https://wisemattic.com/privacy-policy/
